
## ADR-033 Frontend foundation (React + JavaScript + Vite, no TypeScript, no Next.js)
The frontend is a client-rendered React 19 single-page app built with Vite 7, plain JavaScript (JSX) and plain CSS (custom properties, light/dark via prefers-color-scheme), routed with React Router 7. In development, Vite proxies `/api` to the backend (`VITE_API_PROXY_TARGET`, default http://localhost:8000), so the browser sees one origin and the API needs no CORS configuration. All HTTP goes through one `apiFetch` wrapper: JSON in/out, bearer token, RFC 9457 problem details turned into `ApiError`, network failures reported without internals, and a 401 on an authenticated call signs the user out. The access token is kept in sessionStorage (survives a reload, not closing the tab; never localStorage or frontend-set cookies); like any token readable by JavaScript it is exposed to XSS, which React's escaping, no `dangerouslySetInnerHTML` and a short token TTL mitigate. Pages: sign in / register, projects (list + create with visibility), project claims with status and Proof Level badges, and claim detail with the evaluator's reasons, Evidence Packages with integrity state and the timeline. Status wording mirrors the backend and never calls a claim false; every badge explains its meaning. Tests use Vitest + Testing Library + jsdom with a mocked `fetch`, so they need neither a backend nor a network.
